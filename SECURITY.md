# Security policy

This repository is the official marketplace listing for Bridgistic. The code here is synced from [Wordpressistic/bridgistic](https://github.com/Wordpressistic/bridgistic), where fixes are developed and released. Its full policy is in that repo's [SECURITY.md](https://github.com/Wordpressistic/bridgistic/blob/main/SECURITY.md).

**Please don't open a public issue for a vulnerability.** Email **hello@insightistic.com** with the subject `SECURITY: <short summary>`. Include the affected component and version, reproduction steps, and the impact you see.

Only the latest release (1.5.x) is supported. Please upgrade and re-test before reporting.
