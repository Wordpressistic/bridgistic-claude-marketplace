# Security policy

This repository is a **frozen historical mirror**. Bridgistic is developed, released and
patched in [Wordpressistic/bridgistic](https://github.com/Wordpressistic/bridgistic); see its
[SECURITY.md](https://github.com/Wordpressistic/bridgistic/blob/main/SECURITY.md).

**Do not open a public issue for a vulnerability.** Email **support@wordpressistic.com** with
the subject `SECURITY: <short summary>`. Versions published from this mirror (≤ 1.5.2) are not
patched here. Security fixes ship in 1.5.3+ from the canonical repository.
